Для уже работающего сервера начинай с **Инструкции администратора** и **Полезных команд**.
`SERVER.md` содержит первоначальные примеры выпуска `v0.1.0`: этот тег в нашем репозитории
был создан до объединения исходников и для установки не подходит. Новый выпуск получает
новый тег; актуальная процедура приведена в инструкции администратора.

Зафиксированные пути, даты проверки и версии — сведения на момент подготовки инструкций,
а не автоматический статус сервера. Узнать выбранную версию: `readlink -f /opt/nutrition-bot/current`.
Секреты, рабочие базы и личные логи в документацию не включены.

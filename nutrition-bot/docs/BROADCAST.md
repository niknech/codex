# Сообщение всем пользователям

Скрипт `deploy/broadcast.py` запускается на Linux-сервере через Python 3.
Не нужны сторонние библиотеки, пересборка или остановка бота.
Получатели — все уникальные личные чаты из `users`, включая ранее зарегистрированных
пользователей, которых позже убрали из разрешённых ID. Allowlist не фильтруется.
Заблокировавшие бота получатели будут отмечены как failed.

Скопируй скрипт на сервер в `/home/nick/broadcast.py`, затем создай текст:

```bash
nano /home/nick/message.txt
```

Сохрани через Ctrl+O, Enter; выйди через Ctrl+X. Поддерживаются эмодзи и переносы
строк. Markdown/HTML не обрабатываются. Предел — 4096 единиц UTF-16.

Предпросмотр (никому не отправляет и не читает токен):

```bash
sudo python3 /home/nick/broadcast.py /home/nick/message.txt --id news-2026-10-12
```

Отправка:

```bash
sudo python3 /home/nick/broadcast.py /home/nick/message.txt --id news-2026-10-12 --send
```

После просмотра текста введи `ОТПРАВИТЬ`. Для следующего объявления используй новый ID.
Токен читается из `/etc/nutrition-bot/telegram_token`, база —
`/var/lib/nutrition-bot/bot.sqlite3` (только чтение). Для других путей есть
`--db` и `--token-file`; не передавай сам токен через аргументы.

История рассылок хранится отдельно: `/var/lib/nutrition-broadcast/history.sqlite3`.
Не удаляй её ради повтора: она защищает от повторной отправки.
При первом запуске с отправкой фиксируются текст (его хеш) и список получателей.
Повтор с тем же ID продолжает только pending, новые пользователи в него не добавляются.
Число в предпросмотре — текущее число в базе; итог возобновлённой рассылки относится
к первоначально зафиксированному списку.

Статусы: sent — Telegram принял сообщение (не означает, что его прочитали);
failed — Telegram отказал; pending — ещё не отправлено; unknown — доставка неизвестна.
После 429 дождись указанного времени и повтори команду с тем же ID.
После обрыва связи unknown не повторяются автоматически: сначала проверь доставку.
Две рассылки одновременно не запускаются. Скорость — одно сообщение в секунду,
платные рассылки Telegram не включаются.

Проверка без реальных отправок: `python3 -m unittest discover -s tests -p test_broadcast.py`.

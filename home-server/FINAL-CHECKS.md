# Завершение настройки: LAN и автозапуск

Статус на 02.11.2026: владелец предоставил адреса интерфейсов. Домашний интерфейс — enp2s0, маршрут по умолчанию через домашний роутер, адрес получен по DHCP. Другие интерфейсы не менять: их назначение в рамках этой операции не исследовалось. Персональные адреса не публикуются.

Автозапуск immich уже подтверждался как enabled. Tailscale Serve запущен с --bg, доступ с iPhone работает. LAN-привязка применена 02.11.2026, HTTP 200 проверен с сервера. Остались проверка с другого устройства, DHCP-резервирование и проверка после перезагрузки. Резервное копирование остаётся отложенным по просьбе владельца.

## Локальный доступ

Актуальные действия: [раздел Immich](guide/06-immich.md). Ниже сохранено описание уже выполненной настройки.

[configure-lan.sh](configure-lan.sh) предназначен для существующей конфигурации: принимает фактический IPv4 enp2s0, проверяет наличие адреса и HDD, сохраняет Compose перед изменением и добавляет LAN-привязку рядом с localhost. При неверной структуре файла останавливается; при ошибке валидации возвращает исходный файл. Затем включает автозапуск docker/tailscaled/immich и перезапускает только Immich. Скрипт не перезагружает сервер, не меняет роутер и не включает резервное копирование.

Запуск под nick после скачивания скрипта из фиксированного коммита:

```bash
bash configure-lan.sh LAN_IPV4
```

LAN_IPV4 заменить фактическим адресом, иначе скрипт остановится. При ошибке после рестарта диагностировать состояние по [руководству](ADMIN_GUIDE.md); автоматически не менять данные базы. Откат LAN описан там же. Скрипт проверен на синтаксис локально, выполнение на сервере подтверждено 02.11.2026. Повторный запуск без необходимости не требуется.

Проверить с компьютера в домашней сети `http://LAN_IPV4:2283`, затем прежний HTTPS через Tailscale. HTTP в домашней сети не шифруется. Не делать проброс порта 2283 в интернет. Docker может обходить UFW; публикация адреса не является фильтром по IP клиента.

Закрепить текущий адрес enp2s0 за сервером в DHCP роутера до проверки reboot. Иначе при изменении адреса Docker не сможет привязать порт и Immich не запустится. Не менять серверный адрес вручную в Debian без отдельного плана.

## Проверка перезагрузки

После healthy всех четырёх контейнеров, HTTP 200 и успешного входа по LAN, в удобный момент (боты и соединения временно прервутся):

```bash
sudo findmnt --verify --verbose
sudo /usr/local/sbin/immich-check-storage
```

Только если проверки успешны и есть возможность локального доступа при проблемах загрузки:

```bash
sudo reboot
```

После повторного подключения:

```bash
sudo /usr/local/sbin/immich-check-storage
systemctl is-enabled docker tailscaled immich
systemctl is-active docker tailscaled immich
systemctl is-active nutrition-bot adguardvpn-bot tailscale-relay
systemctl --failed --no-pager
cd /home/nick/immich-app
sudo docker compose ps -a
curl -I --max-time 10 http://127.0.0.1:2283
sudo tailscale serve status
```

После инициализации ожидаются четыре healthy и HTTP 200. Отдельно проверить LAN в браузере и iPhone через Tailscale. Записать результаты, не считать автозапуск проверенным только по enabled.

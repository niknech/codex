### Предложенный следующий шаг — пока не подтверждён

Скачать официальные шаблоны в новый закрытый каталог без запуска контейнеров. Выполнять блок целиком в Bash; при ошибке подкоманд оболочка блока завершится, текущая SSH-сессия останется открытой:

```bash
(
set -eu
umask 077
mkdir -m 700 /home/nick/immich-app
cd /home/nick/immich-app
curl -fL --retry 3 https://github.com/immich-app/immich/releases/download/v3.3.5/docker-compose.yml -o docker-compose.yml
curl -fL --retry 3 https://github.com/immich-app/immich/releases/download/v3.3.5/example.env -o example.env
ls -l docker-compose.yml example.env
cat docker-compose.yml
)
```

Если каталог уже существует, остановиться и проверить его содержимое, не удалять и не перезаписывать. На этом шаге `.env` с рабочим паролем ещё не создаётся. После получения Compose предстоит задать пути, пароль, loopback-порт и защиту автозапуска при отсутствии HDD; `docker compose up` пока не выполнять.

## 2026-11-01 — выбор внешнего доступа и проверка WAN

Владелец установил мобильное приложение и выбрал доступ без Tailscale/VPN на телефоне: нужен публичный HTTPS endpoint. Домен пока не определён, провайдер МГТС, доступ к настройкам роутера есть. Серверный Tailscale сохраняется для администрирования.

На скриншоте WAN интернет-интерфейс HSI получает по DHCP адрес из диапазона 100.64.0.0/10. Это Shared Address Space, не публичный IPv4 ([RFC 6598](https://www.rfc-editor.org/rfc/rfc6598)). Для данного WAN это свидетельствует о CGNAT провайдера; одного проброса порта домашнего роутера недостаточно для прямого входящего IPv4-доступа. Полный IP, MAC и скриншот в репозиторий не включены. Поле глобального IPv6 на скриншоте пустое; наличие доступного IPv6 не подтверждено.

Следующий шаг: уточнить у провайдера возможность и стоимость публичного IPv4 без CGNAT и доступность входящих TCP 80/443. Услуга не заказана; цена и условия неизвестны. Если вариант недоступен, рассмотреть VPS с публичным HTTPS и туннелем до домашнего сервера, без дополнительного приложения на телефоне. Покупки, проброс портов и публичная публикация Immich не выполнялись.

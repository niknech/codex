# 1. Подключение и основы

[Оглавление](../../README.md) · [Далее](02-server.md)

## Подключиться дома

1. Включи сервер, дождись загрузки.
2. Подключи ноутбук к обычной домашней сети роутера. Для настройки VPN-раздачи не используй саму NICK-VPN.
3. На Windows нажми «Пуск», набери **PowerShell**, открой его. Права администратора Windows не нужны.
4. **НОУТБУК:**

```powershell
ssh nick@192.168.1.91
```

Это адрес из прошлой настройки. Если роутер выдал другой, найди NICK-SERV в списке его устройств. Закрепи адрес в DHCP роутера, чтобы он не менялся.

При первом подключении SSH спросит о доверии ключу. Сравни отпечаток с сервером через монитор и клавиатуру: `sudo ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub`. Подтверждай `yes`, если это твой сервер. При неожиданной смене ключа сначала выясни причину.

Введи пароль `nick`. Во время ввода нет ни букв, ни звёздочек — это нормально. Приглашение `nick@NICK-SERV:~$` означает, что ты уже на сервере.

## Подключиться вне дома

Включи Tailscale на ноутбуке и войди в свою сеть. **НОУТБУК:**

```powershell
ssh nick@100.111.125.124
```

Это Tailscale-адрес из переписки; если он изменился, возьми новый в приложении Tailscale. Домашний адрес `192.168.1.91` сам по себе из интернета недоступен. Проброс SSH на роутере не нужен.

Если Tailscale сломан, подключайся дома через LAN или монитор. Перезапуск Tailscale через единственное Tailscale-соединение может оборвать доступ.

## Как читать и выполнять команды

| Что видишь | Что это значит |
|---|---|
| `PS C:\Users\Nikita>` | PowerShell на ноутбуке |
| `nick@NICK-SERV:…$` | Терминал сервера |
| `sudo` | Действие с правами администратора сервера |
| `\` в конце строки | Команда продолжается; вставляй весь блок |
| `Ctrl+C` | Прервать команду или просмотр журнала |
| `q` | Выйти из постраничного просмотра |
| `exit` | Выйти из SSH, службы продолжат работать |

Копируй содержимое блока без приглашения `nick@…$`. Значения `ИМЯ_ФАЙЛА` или `SERVER_ADDRESS` нужно заменить своими. При ошибке не выполняй оставшиеся шаги наугад.

## Файлы и редактор

**СЕРВЕР:**

```bash
pwd
ls -lah
cd /home/nick/immich-app
```

`pwd` показывает текущую папку, `ls` — файлы, `cd` меняет папку. `cd ~` возвращает домой. Linux различает большие и маленькие буквы.

Пример открытия настроек:

```bash
sudo nano /etc/nutrition-bot/config.env
```

Стрелками найди строку и исправь. **Ctrl+O → Enter** — сохранить, **Ctrl+X** — выйти. Для выхода без сохранения: Ctrl+X, затем N, если спросит. Перед изменениями делай копию по разделу приложения. Сохранение файла обычно требует отдельного перезапуска службы.

## Передать обычный файл

В отдельном окне **PowerShell ноутбука**, не в SSH:

```powershell
scp "C:\Users\Nikita\Documents\example.txt" nick@192.168.1.91:/home/nick/
```

Скачать обратно:

```powershell
scp nick@192.168.1.91:/home/nick/example.txt "$HOME\Downloads\example.txt"
```

Замени имя на свой файл. Вне дома используй Tailscale-адрес. Для работающих баз данных эти примеры не подходят: нужна [согласованная копия](07-backups.md).

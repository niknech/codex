# Доступ к Immich через Tailscale Serve

Выбран владельцем 02.11.2026. На сервере Tailscale 1.104.1. После исходного `No serve config` владелец выполнил команду Serve: получен HTTPS URL внутри tailnet, proxy к http://127.0.0.1:2283 и сообщение `Serve started and running in the background`. Активация подтверждена; доступ через Safari и вход в Immich на iPhone ещё не проверены. Персональное DNS-имя в репозитории не публикуется.

## Следующий шаг на сервере

```bash
curl -I --max-time 10 http://127.0.0.1:2283
sudo tailscale serve --bg --https=443 http://127.0.0.1:2283
sudo tailscale serve status
```

Сначала убедиться, что локальный Immich отвечает HTTP 200. Если Tailscale предложит ссылку для включения Serve/HTTPS, открыть её в браузере под владельцем tailnet и разрешить необходимые функции. Ссылку активации не публиковать. После завершения посмотреть `serve status`; если конфигурация не появилась, повторить команду Serve.

Команда публикует reverse proxy внутри tailnet согласно его правилам доступа, не во всём интернете. Funnel не включать. Публикация Docker остаётся 127.0.0.1:2283. Флаг --bg сохраняет Serve после выхода из SSH и перезагрузки, пока его не отключат; работу после реальной перезагрузки ещё нужно проверить.

## На iPhone

02.11.2026 владелец подтвердил, что доступ с телефона работает после настройки URL. Загрузка/скачивание фото, автоматическая загрузка и работа после перезагрузки пока отдельно не подтверждены.

Включить Tailscale в той же сети, открыть в Safari точный HTTPS URL из `serve status`. После проверки указать этот URL в Immich, без порта 2283 и без добавления /api. Войти под ранее созданным пользователем Immich. Вход с телефона, загрузку и скачивание проверить отдельно; текущий этап не подтверждает их работоспособность.

Адрес tailnet и ссылки активации в GitHub не сохраняются. Настройки роутера, покупка домена и VPS не требуются. Резервное копирование остаётся отложенным до покупки внешнего HDD.

Для отключения только этой публикации (не выполнять при обычной настройке):

```bash
sudo tailscale serve --bg --https=443 off
```

Источник: [Tailscale Serve CLI](https://tailscale.com/docs/reference/tailscale-cli/serve).

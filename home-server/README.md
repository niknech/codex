## Что не публикуется

В репозитории нет паролей, `.env`, токенов, SSH-ключей, адресов подключения, серийного номера HDD, WWN, фотографий или дампов базы. Указанные hostname, имя локального пользователя и UUID включены по запросу владельца для воспроизводимости настройки; UUID не является паролем. Полные диагностические выводы перед публикацией следует очищать от идентификаторов и персональных данных.

# Первый вход в Immich

Статус: владелец подтвердил работу интерфейса и создание учётной записи администратора 01.11.2026. Повторно регистрацию выполнять не нужно. Логин, email и пароль не сохраняются в репозитории.

Порт опубликован только на 127.0.0.1 сервера. Для первого входа открыть новое окно PowerShell на клиентском компьютере с доступом к серверу через Tailscale. Подставить адрес сервера локально, не публиковать его в репозитории:

```powershell
ssh -N -o ExitOnForwardFailure=yes -L 127.0.0.1:2283:127.0.0.1:2283 nick@SERVER_ADDRESS
```

После ввода пароля отсутствие вывода нормально: окно держит туннель. Открыть в браузере этого компьютера `http://localhost:2283`. Закрытие окна или Ctrl+C завершает туннель, но не останавливает Immich.

Нажать Getting Started / «Начать», указать имя, email и отдельный сильный пароль для Immich. Первый зарегистрированный пользователь становится администратором. Пароль из `.env` предназначен для базы PostgreSQL; для входа в интерфейс использовать новый пароль. Не отправлять учётные данные в чат или GitHub.

После входа подтвердить результат и проверить загрузку/скачивание нескольких тестовых фотографий с сохранением исходников. Массовую загрузку и мобильную автозагрузку отложить до настройки отдельной резервной копии и проверки восстановления. Туннель обеспечивает доступ только на данном компьютере; постоянный доступ через Tailscale предстоит настроить отдельно.

Если локальный порт занят, заменить только левый порт на 12283 (`-L 127.0.0.1:12283:127.0.0.1:2283`) и открыть `http://localhost:12283`.

Источник: [официальные шаги после установки](https://docs.immich.app/install/post-install/).

## Следующая проверка — пока не выполнена

Загрузить через браузер 2–3 тестовых фотографии, сохранив исходники на компьютере. Дождаться миниатюр, открыть фото и скачать оригинал обратно. Убедиться, что скачанный файл открывается; для строгой проверки сравнить SHA-256 исходника и скачанного оригинала через `Get-FileHash -Algorithm SHA256` в PowerShell.

После успешного теста проверить автозапуск при перезагрузке сервера (с учётом краткого перерыва работы ботов и Tailscale). Затем настроить постоянный доступ и независимую резервную копию. До этого не удалять оригиналы и не начинать массовый перенос.

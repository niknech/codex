# Домашний сервер NICK-SERV

Пошаговая инструкция для владельца: от первого подключения до обслуживания бота, VPN, Wi-Fi и фотографий.

**Начни с [подключения к серверу](home-server/guide/01-connect.md). Если что-то сломалось — открой [поиск неисправностей](home-server/guide/08-troubleshooting.md).**

## Как читать

У команд указано место выполнения: **НОУТБУК — PowerShell** или **СЕРВЕР — после SSH**. Выполняй блоки по очереди, останавливайся при ошибке. Таблицы команд — справочник: выбирай нужное действие, не выполняй все строки подряд.

## Структура репозитория

```text
home-server/guide/    — основное руководство для всей системы
home-server/systemd/  — существующая служба Immich и защита диска
home-server/*.md      — прежние материалы установки и история
nutrition-bot/        — исходники и инструкции разработки бота
telegram_alert_analyzer/ — отдельный прежний проект
```

Код бота в `main` и доработки в `nutrition-openai` имеют разную историю. [Новые функции бота](https://github.com/niknech/codex/tree/nutrition-openai/nutrition-bot) и [PR №7](https://github.com/niknech/codex/pull/7) доступны отдельно. Обновление документации не устанавливает код на сервер и не означает, что `main` совпадает с работающей программой. Установленный релиз проверяется в разделе 3.
